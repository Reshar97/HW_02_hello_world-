Управляемая строка в ядре Linux: пример модуля с параметрами
Этот проект содержит модуль ядра Linux, который демонстрирует работу с параметрами модуля, callback-функциями и интерфейсом sysfs. Модуль позволяет собирать строку посимвольно, управляя индексом и значением символа через параметры.
Структура проекта

    Kbuild — конфигурация для сборки модуля.
    Makefile — файл с правилами для сборки, установки, проверки и форматирования кода.
    hello.c — исходный код модуля ядра.

Сборка и использование
1. Сборка модуля

Для компиляции модуля выполните команду в каталоге проекта:

make

В результате будет создан файл hello_world.ko.
2. Форматирование кода

Для приведения исходного кода к единому стилю используется clang-format:

make format

3. Проверка корректности

Запуск скрипта проверки, который тестирует логику работы модуля:

make check

4. Загрузка и выгрузка модуля

Для тестирования модуль загружается напрямую из текущей директории с помощью insmod и выгружается с помощью rmmod.

Загрузка модуля в ядро:

sudo insmod hello_world.ko

При загрузке в системный журнал (dmesg) будет выведено сообщение <имя_модуля>: init.

Выгрузка модуля из ядра:

sudo rmmod hello_world

При выгрузке в журнал будет выведено сообщение <имя_модуля>: exit.
5. Взаимодействие с параметрами через sysfs

После загрузки модуля в каталоге /sys/module/hello_world/parameters/ появятся файлы параметров. Вы можете управлять ими с помощью стандартных команд cat и echo.

    Запись символа:Сначала установите индекс, а затем — значение символа.

    echo 0 > /sys/module/hello_world/parameters/idx   # Установим индекс 0
    echo 72 > /sys/module/hello_world/parameters/ch_val # Запишем символ 'H'

    Примечание: для записи следующего символа ('e') нужно будет изменить индекс на 1.
    Чтение строки:

    cat /sys/module/hello_world/parameters/my_str

    Попытка записи в read-only параметр (вызовет ошибку):

    echo "test" > /sys/module/hello_world/parameters/my_str

    Операция завершится с ошибкой Permission denied, так как параметр предназначен только для чтения.

Особенности реализации

    Логирование: При загрузке (insmod) и выгрузке (rmmod) модуля в системный журнал (dmesg) выводятся сообщения.
    Безопасность: Параметры имеют строгую валидацию. Индекс проверяется на выход за границы массива, а значение символа — на принадлежность к диапазону видимых ASCII-символов (от 32 до 126).
    Read-Only параметр: Параметр my_str реализован без функции установки, что делает его доступным только для чтения.
    Аллокация: В коде используется статический массив, динамические аллокаторы (kmalloc, vmalloc) не применяются.
